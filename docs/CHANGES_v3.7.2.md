# تغییرات نسخهٔ ۳.۷.۲ — صفحهٔ تنظیمات به زبان بصری پنل

نسخهٔ ظاهری. هیچ تنظیمی، هیچ داده‌ای و هیچ رفتاری از OptionTree عوض نشده؛
فقط صفحهٔ «تنظیمات ترانه یار» مثل خودِ داشبورد پنل چیده شده است.

## چه چیزی اضافه شد

1. **سربرگ کامل** — نشان «تنظیمات قالب»، توضیح یک‌خطی، و سه دکمه:
   «ذخیرهٔ تغییرات» (همان submit اصلی را می‌زند)، «بازگشت به پنل»، «دیدن سایت».
2. **ستون فهرست بخش‌ها** — هشت بخش با آیکون و حالت فعال گرادیانی؛ در موبایل
   به نوار افقی قابل اسکرول تبدیل می‌شود.
3. **سرصفحهٔ هر بخش** — آیکون + عنوان + یک جملهٔ راهنما بالای فیلدهای همان بخش.
4. **جست‌وجوی زنده** — با تایپ، فیلدهای **همهٔ** بخش‌ها فیلتر می‌شوند، تعداد
   نتیجه کنار هر بخش می‌آید، بخش‌های بی‌نتیجه کم‌رنگ می‌شوند و پیام «چیزی پیدا
   نشد» فقط در بخش خالی دیده می‌شود. `Esc` پاک می‌کند.
5. **پیوند مستقیم** — `?section=about` یا `#section_about` همان بخش را باز
   می‌کند؛ کارت‌های پنل هم همین پیوند را می‌دهند. بخش فعال در `sessionStorage`
   می‌ماند تا بعد از ذخیره همان‌جا برگردید.
6. **نوار چسبان** — جست‌وجو + دکمهٔ ذخیره زیر نوار مدیریت می‌چسبد (۳۲px دسکتاپ،
   ۴۶px موبایل) و روی محتوا نمی‌افتد.
7. **دکمهٔ ذخیرهٔ تکراری** پایین فرم پنهان شد؛ «بازیابی تنظیمات» به یک لینک
   کم‌رنگ و دور از دست تبدیل شد (تأیید خودش را دارد).

## چه چیزی دست نخورد

- همان مارکاپ OptionTree، همان `jquery-ui-tabs`، همان فرم `options.php` و همان
  کلید `option_tree`. اگر پوسته خاموش شود
  (`define( 'TARANEHYAR_SETTINGS_SKIN', false )` یا `ab_admin_ui = off`)،
  دقیقاً ظاهر قبلی برمی‌گردد.
- همهٔ CSS زیر `body.tara-settings-screen` قفل است؛ هیچ صفحهٔ دیگری از پیشخوان
  تغییر نمی‌کند.
- فایل ما بعد از `ot-admin.css` چاپ می‌شود (هوک
  `admin_print_styles-taranehyar_page_ot-theme-options` با اولویت ۹۹) تا هیچ
  قاعدهٔ قدیمی روی ظاهر تازه ننشیند.
