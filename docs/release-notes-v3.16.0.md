# ترانه‌یار ۳.۱۶.۰ — دور P0 ممیزی APEX

این نسخه فقط ضعف‌های P0 گزارش `docs/APEX_AUDIT_2026-10.md` را برمی‌دارد؛ هیچ داده‌ای مهاجرت نمی‌شود و عقب‌گرد به ۳.۱۵.۰ بدون تغییر پایگاه‌داده ممکن است.

- **جست‌وجو دیگر بی‌صدا نمی‌شکند.** درخواست AJAX جست‌وجو بدون nonce معتبر پاسخ ۴۰۳ می‌گیرد و عبارت بیش از ۸۰ نویسه بریده می‌شود. پاسخ JSON حالا نوع اثر و شمارش کل را هم دارد و اگر درخواست شکست بخورد، پیام «جست‌وجو ناموفق بود» با دکمهٔ «تلاش دوباره» می‌آید — پنجرهٔ جست‌وجو بسته نمی‌شود.
- **صفحات نتیجهٔ جست‌وجو از ایندکس خارج شدند** (`noindex, follow`، فقط `is_search()`). robots.txt و sitemap دست نخورده‌اند و با فیلتر `tara_seo_noindex_search` می‌توانید این رفتار را برگردانید.
- **تاریخ نمایشی صادقانه شد.** اگر متای تاریخ انتشار واقعی (`_tara_release_date` / `release_date` / `tara_release_date`، با پشتیبانی از خروجی آرایه‌ای ACF) وجود داشته باشد، برچسب «تاریخ انتشار» می‌گیرد؛ وگرنه «انتشار در سایت» با تاریخ نوشته. همان مقدار در `datePublished` و `<time datetime>` صفحهٔ آهنگ هم استفاده می‌شود.
- **«سایر آهنگ‌های هنرمند» یک نسخه شد.** در `single.php` چهار بلوک موازی با دو استراتژی کوئری وجود داشت که در تنظیمات مختلف دو فهرست متفاوت می‌داد. حالا هر دو حالت به یک تابع می‌رسند: اول تاکسونومی هنرمند، بعد متای `artist`؛ با نرمال‌سازی فارسی (ي/ك/ة/نیم‌فاصله) و مرتب‌سازی تاریخ نزولی. مارک‌آپ و جایگاه قبلی حفظ شده است.
- **صفحهٔ اصلی خالی نیست.** چهار بخش تازهٔ داده‌محور اضافه شد: «تازه‌ترین انتشارها» (فقط آثاری با تاریخ انتشار واقعی، و اگر کمتر از ۴ مورد باشد ساخته نمی‌شود)، «موزیک‌ویدیوهای تازه»، «آلبوم‌های تازه»، «حال‌وهوا» و «تازه‌ترین اخبار». هر بخش بدون داده صفر خروجی دارد و از «تنظیمات قالب → صفحه اصلی» جدا خاموش می‌شود (`home_sec_releases`، `home_sec_video`، `home_sec_album`، `home_sec_mood`، `home_sec_news`).
- **هیرو دیگر با نبودِ اثر ویژه حذف نمی‌شود**؛ به «تازه‌ترین آثار» با برچسب صریح برمی‌گردد (`data-tara-hero-source="latest"`). به‌محض ثبت `vip_song` رفتار قبلی برمی‌گردد.
- **ناوبری و ساختار:** زیرمنو با کیبورد هم باز می‌شود (`focus-within`)، صفحهٔ اصلی در صفحهٔ اول H1 دارد، لینک کوتاه صفحهٔ آهنگ با `home_url()` ساخته می‌شود.
