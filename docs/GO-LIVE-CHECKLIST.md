# چک‌لیست انتشار — کارهایی که فقط از طرف شما (مالک سایت) شدنی است

این فهرست «باگ سورس» نیست؛ چیزی است که در کد قالب قابل انجام نبود یا به دسترسی
هاست/پیشخوان نیاز دارد. هر بند اختیاری است و اگر انجام نشود چیز دیگری خراب نمی‌شود —
فقط سودش را از دست می‌دهید.

---

## ۱) قبل از آپلود (۲ دقیقه)

- [ ] از `wp-content/themes/javanseda` یک zip بکاپ بگیرید (یا از پیشخوان → ابزارها).
- [ ] اگر افزونۀ کش/بهینۀ عکس دارید، کش را آمادهٔ پاک‌کردن کنید (بعد از آپلود پاک می‌کنیم).
- [ ] فایل‌های این نسخه: زیپ `drop-in-v3.3.8.zip` ⇒ مسیرهایش را **همان‌طور که هست** در
      `wp-content/themes/javanseda/` بریزید (پوشه‌های `fonts/` و `css/` و `inc/` ساخته می‌شوند).
- [ ] **پنج فایل woff2 حتماً آپلود شوند** (`fonts/*.woff2`). اگر جا بیفتند، سایت کار می‌کند
      (fallback woff) ولی سودِ ۲۰٪ فونت را نمی‌گیرید.
- [ ] `css/ab-ui.css` و `inc/ab-ui-guard.php` را هم بریزید؛ اگر فقط یکی جا بیفتد هم
      مشکلی پیش نمی‌آید (گارد بی‌صدا کنار می‌رود).

## ۲) بعد از آپلود (۵ دقیقه)

- [ ] کش افزونه + `Ctrl+F5` (Hard Refresh) روی سه نشانی: `/` ، یک صفحۀ آهنگ، `/singers/`.
- [ ] DevTools → Network → Font: `vazir-fd.woff2` با `font/woff2` ≈ 35KB ببینید.
- [ ] DevTools → Elements: اولین لینک داخل `<body>` باید
      `<a class="ab-skip-link" href="#centers_box">` باشد؛ با یک بار `Tab` باید ظاهر شود.
- [ ] در صفحۀ یک **آلبوم**: دیگر دو `id="audio"` ندارید (در کنسول: `document.querySelectorAll('#audio').length` ⇒ **۱**)
      و ردیف کنترلِ پلیر دوم دیگر نمایش داده نمی‌شود؛ فهرست دانلود ردیف‌ها باید باشد.
- [ ] `curl -sI https://ahangban.ir/ab-mobile-probe.php?self=1` (یا بازکردن در مرورگر
      ناشناس) باید متن «کلید نامعتبر است» بدهد، نه سورس فایل.
- [ ] PageSpeed/جایزمتریک را یک‌بار قبل و بعد بگیرید تا اثر حذف `COUNT` و woff2 را ببینید.

## ۳) یک‌بار، ولی لازم برای سود کامل

- [ ] **بازتولید تصاویر** (تا `thumb2x` ساخته شود؛ بدونش `srcset` فقط ۱۹۰ را می‌فرستد):
      `wp media regenerate images --size=thumb2x` یا افزونۀ Regenerate Thumbnails.
      روی میزبانِ شلوغ این کار را در ساعت خلوت انجام دهید (زمان‌بر است).
- [ ] **منوی موبایل**: نمایش → menuها → «محل نمایش» را روی منوی موبایل بگذارید؛ اگر خالی
      باشد کشوی موبایل خالی می‌ماند (باگ قالب نیست).
- [ ] **شناسنامۀ آهنگ**: فیلدهای `artist` · `composer` · `lyricist` · `arranger` · `mixer` ·
      `producer` · `duration` (ACF) را برای پست‌های پربازدید پر کنید تا هم بلوک شناسنامه
      و هم `duration` در اسکیمای MusicRecording بیاید.
- [ ] **شبکه‌های هنرمند**: در ویرایش برچسب هنرمند، `afacebook` / `atelegram` /
      `ainstagram` / `atwitter` را پر کنید (آیکون‌های خالی چاپ نمی‌شوند، پس ضرری ندارد —
      ولی تا پر نشود چیزی هم نمی‌بینید).

## ۴) داده/ساختار (اختیاری، ولی روی سئو اثر دارد)

- [ ] یکدست‌کردن نشانی‌ها (قبل از اجرا حتماً dry-run):
      ```
      wp search-replace 'http://www.ahangban.ir' 'https://ahangban.ir' --dry-run
      wp search-replace 'http://www.ahangban.ir' 'https://ahangban.ir'
      ```
- [ ] لینک‌های `http://dl.…` روی صفحۀ https = **mixed content**؛ از
      `http://dl.golsarmusic.ir/...` به `https://dl.ahangban.ir/...` (یا همان `//`) منتقل شوند.
- [ ] ترم‌های دوبل `singer` را ادغام کنید (نمایش → برچسب‌ها): اگر یک هنرمند دو برچسب
      با املا/فاصلۀ متفاوت دارد، یکی‌شان ۴۰۴ می‌دهد.
- [ ] اگر افزونۀ سئو فعال است: عنوان سئو/`title-tag` را با لایۀ `inc/ab-seo.php`
      هماهنگ کنید (قالب عمداً `add_theme_support('title-tag')` ندارد؛ اگر افزونه هم
      عنوان بسازد، دوباره‌می‌شود). یک `Yoast/RankMath` title test روی `/roozbeh-bemani-booseye-akhar/`.
- [ ] سایت‌مپ + `robots.txt` را یک‌بار باز کنید و مطمئن شوید `/singer/…` ایندکس می‌شود.

## ۵) پاک‌سازی

- [ ] **`ab-mobile-probe.php` را از ریشهٔ هاست حذف کنید** وقتی کارتان با گزارش موبایل
      تمام شد (این نسخه اکشن‌هایش را قفل کرده، ولی فایلِ کاوشگر نباید همیشگی بماند).
- [ ] اگر پوشۀ موقت کاوشگر فایل ذخیره کرده، `?rm=1&k=AHANGBAN-PROBE-306` و بعد حذف فایل.
- [ ] بلوک‌های تبلیغ Option Tree (`ads_bt` / `adsjs_bt` / `ads_sg` / `adsjs_sg`) عمداً
      escape نشدند (HTML دست‌ساز خودتان است)؛ فقط مطمئن شوید **حساب کاربری** که به
      Option Tree دسترسی دارد قابل‌اعتماد است — تنها راه امنِ همین مورد، محدودکردن
      دسترسی است نه escape.

## ۶) اگر چیزی دوست ندارید

| می‌خواهم… | کاری که می‌کنم |
|-----------|----------------|
| لینک پرش نباشد | `define( 'JAVANSEDA_SKIP_LINK', false );` |
| preload فونت خاموش | `define( 'JAVANSEDA_PERF_PRELOAD_FONTS', false );` |
| گارد ab-ui.css خاموش | `define( 'JAVANSEDA_UI_GUARD', false );` |
| JSON-LD آهنگ خاموش | `define( 'JAVANSEDA_MUSIC_SCHEMA', false );` |
| کارآمار روی کاور خاموش | `define( 'JAVANSEDA_CARD_STATS', false );` |
| کل لایۀ شیشه‌ای خاموش | `define( 'JAVANSEDA_GLASS_UI', false );` |
| بازگشت کامل | فایل‌های `rollback-v3.3.8.zip` را روی همان مسیرها بریزید (فایل‌های نسخۀ 3.3.7) |

هر `define` را در `wp-config.php` و **بالای** خط `/* That's all, stop editing! */` بگذارید.

## ۷) اگر «آپدیت قالب مادر» همه‌چیز را خراب کرد

1. هیچ کاری نکنید؛ لایۀ اختصاصی به‌طور خودکار از `css/ab-ui.css` برمی‌گردد
   (گارد، با کش ۱۲ ساعته). برای اطمینان آدرس سایت + `?ab_uiguard=1` (با لاگین مدیر) بزنید.
2. اگر می‌خواهید برای همیشه مطمئن شوید: `docs/CHILD-THEME.md` را بخوانید و یک child
   theme بسازید؛ بعد از آن آپدیت مادر هیچ‌وقت `style.css` شما را لمس نمی‌کند.
