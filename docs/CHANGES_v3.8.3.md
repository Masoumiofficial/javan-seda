# ترانه یار ۳.۸.۳ — لوگوی روز/شب، بنر ویژهٔ ۱۹۲۰×۸۴۰، آیکونِ استانداردِ تمام‌صفحه

تاریخ: ۲۰۲۶-۱۰-۲۹ · نسخهٔ قبلی: ۳.۸.۲

این نسخه سه خواستهٔ تازهٔ مالک را انجام می‌دهد و هفت پیشنهادِ به‌سازی را که
تأیید شد پیاده می‌کند. هیچ صفحه یا مارکاپی حذف نشده و همهٔ تغییرها تست
خودکار دارند.

## ۱) لوگوی جدا برای روز و شب

- **ترانه یار ← پیشخوان ← «لوگوی سایت — روز و شب»**: دو ستون با پیش‌نمایشِ
  مستقل؛ هر کدام فرمِ خودش را دارد (آپلود از کتابخانهٔ رسانه، آدرس دستی،
  بازگردانی به پیش‌فرض). پیش‌نمایشِ لوگوی شب روی پس‌زمینهٔ تیره است تا
  همان‌جا که واقعاً می‌نشیند ارزیابی شود.
- کلید تازه در `option_tree`: **`logo_night`** (کنار `logo`). پس تنظیمات
  OptionTree و پنل، همان یک مقدار را می‌بینند.
- **اگر لوگوی شب خالی باشد، همان لوگوی روز استفاده می‌شود** ⇒ هیچ سایتی با
  به‌روزرسانی خالی/سفید نمی‌شود.
- سربرگ دسکتاپ و کشوی گوشی هر دو **دو تصویر** چاپ می‌کنند و CSS فقط یکی را
  نشان می‌دهد (`.ab-logo__img--day` / `--night`). تعویض، یک قاعدهٔ CSS است؛
  هیچ درخواستِ تازه‌ای در لحظهٔ تغییرِ حالت ساخته نمی‌شود.
- تابع‌های تازه: `tara_logo_raw()`، `tara_logo_night_url()`، `tara_logo_img()`.
- اندازهٔ پیشنهادی هر دو: **۳۰۰×۸۰** PNG/SVG شفاف (نمایش ۱۵۰×۴۰).

## ۲) بنر اسلایدر ویژه: از ۶۴۰×۳۶۰ به **۱۹۲۰×۸۴۰**

- سایز تصویرِ تازهٔ وردپرس: `add_image_size( 'tara-vip', 1920, 840, true )` —
  همان نسبتِ ۱۶:۷ کادرِ اسلایدر، پس هیچ برشی نمی‌خورد.
- **صفحهٔ ویرایش نوشته** یک جعبهٔ تازه گرفت: «بنر اسلایدر ویژه — ۱۹۲۰×۸۴۰»
  با انتخاب‌گرِ رسانهٔ خودِ وردپرس (`wp.media`)، پیش‌نمایش، حذف، و راهنمای
  «WebP کیفیت ۸۰، زیر ۳۰۰ کیلوبایت».
- مقدار در متای **`_tara_vip_banner`** (شناسهٔ پیوست) ذخیره می‌شود، نه در
  `vip_img`. دلیل: فیلد ACF هنگامِ ذخیرهٔ نوشته مقدارِ خودش را روی همان کلید
  می‌نویسد و اگر هر دو یکی باشند، یکی بی‌صدا پاک می‌شود.
- `inc/vip_slider.php` اول این کلید را می‌خواند، بعد فیلدِ قدیمیِ ACF و در
  آخر کاور آهنگ. ابعاد مارک‌آپ هم `1920×840` شد (بدون CLS).

## ۳) آیکون استانداردِ تمام‌صفحهٔ ویدیو

- به‌جای دو گوشهٔ مورّبِ کوچک، **چهار گوشهٔ استاندارد** (SVGِ درون‌خطی، رنگ
  از `currentColor`) و در حالت تمام‌صفحه **آیکونِ «خروج»** با چهار گوشهٔ
  رو‌به‌داخل.
- دکمه `aria-pressed` دارد و `aria-label`/`title` بین «تمام‌صفحه» و «خروج از
  تمام‌صفحه» عوض می‌شود (`syncFsLabels()` در `js/tara-player.js`).

## ۴) تنظیمات OptionTree زیرِ منوی «ترانه یار»

این کار از ۳.۷.۴ انجام شده بود و بررسی شد: با فیلترِ `ot_theme_options_parent_slug`
صفحهٔ تنظیمات زیرِ منوی **ترانه یار ← تنظیمات قالب** است، نه «نمایش».
عنوان‌ها هم فارسی شده‌اند. هیچ‌کاری لازم نبود؛ فقط در تست تثبیت شد.

## ۶) فشرده‌سازی CSS (جزئیات)

- `python3 tools/minify-css.py` → `css/tara-ui.min.css`، `tara-home.min.css`،
  `tara-artist.min.css`، `ab-ui.min.css`، `ab-glass.min.css`، `style.min.css`.
- **۴۴۲KB → ۲۷۵KB (−۳۸٪)** برای همین شش فایل.
- فشرده‌ساز محافظه‌کار است: رشته‌ها و `url(…)` دست‌نخورده، فاصلهٔ `calc()`
  حفظ می‌شود، و بعد از تولید تعداد `{}`/`@media`/`url(` با منبع مقایسه
  می‌شود؛ اگر برابر نبود فایل نوشته نمی‌شود.
- قاعدهٔ تازگی: فشرده فقط وقتی سرو می‌شود که از منبع **تازه‌تر یا مساوی**
  باشد ⇒ فراموشیِ اجرای ابزار هرگز CSS کهنه را سرو نمی‌کند.
- `style.css` اصلی سر جایش می‌ماند (هدر قالب و بازگشتِ آسان).
