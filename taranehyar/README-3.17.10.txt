شاهد ۲ — vip_slider
----------------------------------------------------------------
کدِ داخلِ حلقه در ۳.۱۵.۰ و الان یکی است.
تفاوت در **این است که حلقه اجرا می‌شود یا نه**:

  ۳.۱۵.۰:
    $tara_vip_query = new WP_Query( vip_song LIKE '1' );
    if ( $tara_vip_query->have_posts() ) { ... }

    اگر vip_song خالی باشد → have_posts() = نه
    → کل بلوک اسلایدر چاپ نمی‌شد
    → صفر کار، صفر زمان

  از ۳.۱۶.۰:
    if ( ! $tara_vip_query->have_posts() ) {
        $tara_vip_fallback = true;
        $tara_vip_query = new WP_Query( تازه‌ترین نوشته‌ها );  ← fallback
    }

    اگر vip_song خالی باشد → ۵ اسلایدِ کامل رندر می‌شود
    → و حلقه برای هر اسلاید: ACF + تصویر + srcset + متا

و روی سایت شما (اندازه‌گیری در staging با ۱۲۰٬۰۰۰ ردیف متا):
    vip_num = '' → مؤثر: 5
    کوئریِ vip_song: 0 نتیجه       ← خالی است
    fallback: 5 نتیجه               ← فعال می‌شود
    هزینهٔ ۵ اسلاید: 2ms            ← روی SQLite

روی هاست شما همان ۵ اسلاید ۲۳٬۵۱۱ms گرفت.
این تفاوت روی MySQL یعنی کارِ هر اسلاید بسیار گران‌تر است.

نکته: fallback **هیچ سوئیچی ندارد**. فقط کل اسلایدر با fixbvip
خاموش می‌شود. پس تا وقتی vip_song خالی است، این ۵ اسلاید
همیشه رندر می‌شوند.
