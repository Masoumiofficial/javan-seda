ترانه‌یار — نسخهٔ ۳.۱۷.۶
================================================================
تاریخ: 2026-10-15
موضوع: رفعِ خطای «به‌دلیل داشتن مشکلی جدی، افزونه فعال نشد» (ACF Pro)

----------------------------------------------------------------
۱) علت — دقیقاً چه اتفاقی می‌افتاد؟
----------------------------------------------------------------
فایل inc/acf-compat.php برای اینکه قالب بدون ACF هم کار کند،
توابع ACF را خودش تعریف می‌کرد:

    if ( ! function_exists( 'get_field' ) ) {
        function get_field( $key, $post_id = false, $format_value = true ) { ... }
    }

ولی این چک فقط *در لحظهٔ لودِ قالب* کار می‌کند. وقتی شما
دکمهٔ «فعال‌سازی» ACF Pro را می‌زدید، این ترتیب رخ می‌داد:

    ۱) وردپرس قالب را لود می‌کرد  →  get_field() ساخته می‌شد
    ۲) وردپرس فایل ACF Pro را include می‌کرد
    ۳) ACF هم get_field() را تعریف می‌کرد
    ۴) ⇒ Fatal error: Cannot redeclare function get_field()

و وردپرس به‌جای نصب، پیام می‌داد:

    «به‌دلیل داشتن مشکلی جدی، افزونه فعال نشد.»

یعنی قالب عملاً جلوی نصب ACF Pro را می‌گرفت.
همین برای the_field, have_rows, get_sub_field, the_row,
get_row_index, the_repeater_field هم بود.

----------------------------------------------------------------
۲) اصلاح
----------------------------------------------------------------
الف) همهٔ توابع سازگاری به پیشوند اختصاصی خودمان منتقل شدند:
       get_field      →  tara_get_field
       the_field      →  tara_the_field
       have_rows      →  tara_have_rows
       get_sub_field  →  tara_get_sub_field
       the_row        →  tara_the_row
     این نام‌ها هرگز با ACF تضاد نمی‌کنند.

ب) نام‌های عمومی (get_field و …) دیگر هنگام لودِ قالب
     تعریف نمی‌شوند. پس فعال‌سازی ACF هیچ‌وقت به تضاد نمی‌خورد.

ج) ۳۹ فراخوانی در ۱۲ فایل قالب به tara_* تبدیل شدند.

د) حالت دوگانه حفظ شد:
       • اگر ACF فعال باشد  →  tara_get_field داده را از ACF می‌گیرد
       • اگر نباشد          →  از post meta (مثل قبل)

هـ) ab-terms-admin.php که از acf_get_field_groups استفاده می‌کند
     گاردِ function_exists دارد — دست‌نخورده ماند.

----------------------------------------------------------------
۳) آزمون‌ها
----------------------------------------------------------------
• شبیه‌سازی فعال‌سازی ACF در حالی که قالب لود شده:
      قبل  : Fatal error: Cannot redeclare function get_field()
      بعد  : ✔ ACF لود شد بدون تضاد  |  ACF_VERSION = 6.3.0

• رندر بدون ACF:
      get_field موجود؟ NO ← درست
      tara_get_field موجود؟ YES ← درست
      صفحه سالم رندر می‌شود

• ۸۹ فایل PHP: صفر خطای سینتکس
• ۲۴۳/۲۴۳ آزمون سبز

----------------------------------------------------------------
۴) نصب
----------------------------------------------------------------

باید بدون خطا فعال شود.

اگر باز هم خطا داد، متن دقیق خطا را بفرستید — احتمالاً از
افزونهٔ دیگری است، نه از قالب.
