# نقشۀ تغییرات — نسخۀ 3.3.2 (جایگاه «متن آهنگ» زیر لینک‌های دانلود)

تاریخ: 2026-10-18 · زنجیره: `3.3.1` → **`3.3.2`**

## تصمیم و دلیل

ترتیب قبلی صفحۀ نوشته: کاور → توضیحات → **متن ترانه** → شبکهٔ اجتماعی → شناسنامه → ویدیو → **پلیر** → **لینک‌های دانلود**.
روی دسکتاپ بد نبود، ولی روی موبایل یک ستون متن بلند، دکمۀ پخش و دکمۀ دانلود را از دید اول پنهان می‌کرد — یعنی
قبل از رسیدن به «قصد اصلی کاربر» (شنیدن/دانلود) باید اسکرول می‌کرد.

ترتیب جدید: کاور → توضیحات → شبکهٔ اجتماعی → شناسنامه (قبل از پلیر) → ویدیو → **پلیر** → **لینک‌های دانلود** → **متن ترانه** → شناسنامه (بعد از دانلود) → فوتر پست → اشتراک → برچسب‌ها → مرتبط‌ها.

چهار نکتهٔ ایمنی که بررسی شد:
1. **متن حذف نشده، فقط جابه‌جا شده** — همان باکس، همان `<section class="music_lyrics_box">`، همان دکمۀ «کپی متن ترانه» (اسکریپتش داخل خود باکس با `ob_get_clean()` می‌آید، پس با باکس جابه‌جا می‌شود و `id` ها یکتا می‌مانند).
2. **سئو نمی‌شکند:** JSON‑LD اصلی (`MusicRecording` + `MusicComposition` + `lyrics`) روی `wp_head` توسط `inc/ab-seo.php` چاپ می‌شود و به این باکس وابسته نیست. شاخۀ fallback همان JSON‑LD داخل باکس است؛ اگر کسی `inc/ab-seo.php` را نداشته باشد، اسکریپت در `<body>` چاپ می‌شود که برای Google معتبر است، فقط دیرتر در سند می‌آید.
3. **`the_content()` دست‌نخورده** بالای صفحه می‌ماند (توضیحات کوتاه)، پس کلمات کلیدی اول سند همچنان بالا هستند.
4. **هیچ کوئری، هوک سراسری، تاکسونومی یا تغییری در دیتابیس** انجام نشد.

منطق اضافه‌شده (تمامِ تغییر PHP):

```php
$taranehyar_lyrics_position = 'end';
if ( function_exists( 'ot_get_option' ) && 'off' === ot_get_option( 'lyrics_after_download' ) ) {
	$taranehyar_lyrics_position = 'here';
}
$taranehyar_lyrics_position = apply_filters( 'taranehyar_lyrics_position', $taranehyar_lyrics_position );
```

- پیش‌فرض = رفتار جدید؛ اگر تنظیم هرگز ذخیره نشده باشد `ot_get_option()` مقدار خالی می‌دهد ⇒ همان `'end'`.
- بازگشت با یک کلیک: **تنظیمات قالب → صفحۀ دانلود آهنگ → «متن ترانه زیر لینک دانلود» = خاموش** (بدون ویرایش فایل).
- برای توسعه‌دهنده: `add_filter( 'taranehyar_lyrics_position', function( $p ) { return 'here'; } );`
- لایۀ `inc/ab-credits.php` یا `inc/ab-seo.php` نصب نباشد؟ فقط از `function_exists` استفاده شده و چیزی نمی‌شکند.
