## سنجه‌های تازهٔ این نسخه (۱۰ مورد)

**اسلایدر**
- کادر متن روی کاور حذف شده (نه `.ty-hero-slide__body`، نه `.ty-hero-slide__play`)
- تصویر با نسبت `16 / 7` و `object-fit: cover` کل کارت را می‌پوشاند
- بدون owl فقط اسلاید اول دیده می‌شود (`:not(.owl-loaded)`)
- مارک‌آپ PHP هم دیگر «پیشنهاد ویژه» و دکمهٔ «شنیدن و دانلود» ندارد

**پلیر**
- اسکریپت درون‌خطی `tara-runtime-inline` با کلید `tara-night`
- خودترمیمیِ بارگذاری فایل پلیر (`data-tara-ready` + `appendChild`)
- «صفحهٔ آهنگ» روی همان صفحه پنهان می‌شود (`$tara_same_page`)
- «فهرست پخش» برای یک قطعه پنهان می‌شود (`$tara_total > 1`)
- پلیر صفحهٔ اصلی: پشتیبان برای نوشته‌های دارای `music320`/`music128`

**تنظیمات**
- جابه‌جایی بخش‌ها درون‌خطی (`tara-tabs-ready`)
- هر گزینه جمع‌شونده (`has-label` / `is-open`)
- دکمهٔ «باز کردن همه» و «بستن همه»

**شناسنامه و دکمهٔ بالا**
- کادر سفید پشت نام‌ها حذف شده (`background: transparent !important`)
- `.top_page.is-shown` (نمایش بدون jQuery)

## آزمون رفتاری (jsdom، خارج از مخزن)

- اسکریپت درون‌خطی: کلیک روی آیکون ماه ⇒ `body.night` + `localStorage=1`؛
  کلیک دوم ⇒ برگشت؛ اسکرول ⇒ `.top_page.is-shown`؛ کلیک ⇒ `scrollTo(0)`
- هستهٔ تنظیمات: فقط پنل فعال دیده می‌شود، تب دوم پنل دوم را باز می‌کند،
  ردیف بسته پنهان و با کلیک باز می‌شود، «باز کردن همه» همه را باز می‌کند،
  `location.hash` هم‌گام می‌شود
- پلیر: کلیک روی کارت ⇒ `audio.src` درست، پاپ‌آپ فهرست با ۲ ردیف باز می‌شود
