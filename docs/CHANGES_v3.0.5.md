# مستند نسخهٔ 3.0.5 — «محتوای نوشته در موبایل نمایش داده نمی‌شود» + کاوشگرِ رندر

شاخه: `arena/aa59ef50-javan-seda` · تگ: `v3.0.5` · PR #3

---

## ۱. علامت
روی موبایل: باکسِ نوشته (`article.single_posts` / `#centers_box`) دیده می‌شود، اما
**محتوا** (توضیحات، کاور، باکس متن ترانه، پلیر، لینک‌های دانلود) نمی‌آید. ابزارک سایدبار
درست است و دسکتاپ کاملاً سالم.

## ۲. آنچه با بازبینی ساکن رد شد (تا شما وقت تلف نکنید)
| فرضیه | بررسی | نتیجه |
| :--- | :--- | :--- |
| CSS قالب محتوا را در موبایل پنهان می‌کند | تمام مدیا‌کوئری‌ها برای `.single_content_box`، `.single_posts`، `.music_lyrics_box`، `.dl_links_box`، `#centers_box` | **نه** — هیچ `display:none` / `height:0` / `visibility:hidden` روی اینها نیست؛ فقط `.mobile_more_artist` و `.rel_sing_bbt .left_artists_pp` پنهان می‌شوند (عمدی) |
| `line-height:1px` ریستِ متن را می‌بلعد | `body{line-height:1px}` در ریست وجود دارد ولی بعدتر `body{…line-height:25px…}` بازنویسی‌اش می‌کند | **بی‌اثر** |
| تگِ بسته‌نشده، محتوا را داخل هدر موبایل می‌اندازد | شمارش تگ‌های `inc/mobiles_header.php`: `header` ۱/۱، `div` ۱۲/۱۲، عمق نهایی ۰ | **سالم** |
| JS قالب محتوا را مخفی می‌کند | `js/scripts.js` — تنها `fadeIn/fadeOut` مال `.top_page` و `.bodydeactive` است | **بی‌گناه** |

| خطای PHP در مسیر موبایل | `CSS_Menu_Maker_Walker` در قالب تعریف نشده است اما در `functions.php` رمزنگاری‌شده تعریف است و در نسخهٔ ۳.۰.۱ هم همین مسیر روی همهٔ دستگاه‌ها اجرا می‌شد | **نه** |

⇒ یعنی محتوا یا **در HTML تولید نمی‌شود** (سمت PHP: یک فیلترِ موبایل‌محور در قالب
رمزنگاری‌شده یا یک پلاگین) یا **تولید می‌شود و زیر یک لایه/کش گیر کرده**. این دو را فقط
می‌شود روی سرور شما از هم تشخیص داد؛ پس ابزارش ساخته شد.

## ۳. افزوده‌های این نسخه

### الف) کاوشگرِ رندرِ موبایل ↔ دسکتاپ — `?ab_mobile_probe=1`
همان URL را **روی خودِ سرور** دو بار رندر می‌کند (یک‌بار با UA آیفون، یک‌بار با UA دسکتاپ،
با هدر `no-cache`) و برای هر دو گزارش می‌دهد:
* کد HTTP و حجم HTML؛
* تعدادِ occurrence هر علامت: `<article`، `single_content_box`، کاور، `music_lyrics_box`،
  `dl_links_box`/`dl_linksv_box`، `music_box_player`، `id="left_side"`، `id="mobiles_header"`،
  `ab-has-mh`، `ab-header-critical`، `id="footer"`؛
* تقارن تگ‌های `div` / `header` / `main` / `article` در HTMLِ واقعی؛
* **تودرتویی**: آیا `</header>`ِ هدر موبایل قبل از `<article>` بسته شده؛
* هدرهای کش/CDN پاسخ (`x-cache`، `cf-cache-status`، `x-litespeed-cache`، `age`، …)؛
* یک برش ۴۲۰ کاراکتری از HTML اطراف `single_content_box`؛
* و **نتیجه‌گیری**: «محتوا در HTML موبایل نیست ⇒ PHP» در برابر «هست ⇒ CSS/JS/کش».

همین گزارش به‌عنوان بخش «۹.۵» داخل `?ab_sidebars_diag=1` هم آمده. فقط برای مدیر،
فقط‌خواندنی، بدون هیچ نوشتن در دیتابیس.

### ب) نجات‌دهندهٔ محتوا — `javan_seda_content_rescue()`
فیلتر روی `the_content` در اولویت ۹۹۹۹ که **فقط و فقط** وقتی دخالت می‌کند که خروجی
`the_content` کاملاً خالی باشد و `$post->post_content` پر باشد؛ آن‌گاه
`do_shortcode` + `wpautop` روی محتوای خام اعمال می‌شود. روی نوشته‌های سالم هیچ اثری ندارد.
خاموش‌کردن: `define( 'JAVANSEDA_CONTENT_RESCUE', false );`
هر بار که این نجات فعال شود، پرچم `javan_seda_content_rescued` ثبت می‌شود و در گزارش
تشخیصی دیده می‌آید ⇒ یعنی یک فیلترِ موبایل‌محور محتوا را خالی کرده بود.

### ج) دو قاعدهٔ ایمنیِ موبایل (inline در `header.php` + بلوک ۲۱ `style.css`)
```css
.tarlanweb_center{max-width:100% !important;}        /* ظرف ثابت‌عرض محتوا را در عرض باریک نبُرد */
#centers_box,.single_content_box{overflow:visible;}  /* برش عمودی/افقی ناخواسته در حالت fixed */
```

## ۵. how to — ۳ دقیقه، همین الان
1. با مرورگر **موبایل** و در حالت لاگینِ مدیر، همین آدرس را باز کنید:
   `https://ahangban.ir/<نوشته>/?ab_mobile_probe=1`
2. متن خروجی را (کامل) برایم بفرستید. سه خطِ آخرِ «نتیجه‌گیری کاوشگر» تکلیف را روشن می‌کند.
3. موازی این را هم روی گوشی چک کنید: در «View source» (یا با افزودهٔ View Source) دنبال
   `single_content_box` بگردید. **اگر در HTML بود ولی روی صفحه نبود** ⇒ مشکل CSS/JS/کش است،
   **اگر در HTML نبود** ⇒ مشکل PHP است و خطِ «نجات محتوا» در گزارش می‌گوید چه اتفاقی افتاده.
4. اگر در گزارش، `x-cache: HIT` یا `cf-cache-status: HIT` دیدید: نسخهٔ کهنه سرو می‌شود؛
   کشِ استاتیکِ هاست و CDN را با هم پاک کنید (فقط کش HTML کافی نیست).

## ۶. کنترل‌ها

`Version: 3.0.5` · `javanseda/` و `drop-in/` یکسان (مانیفست SHA-256 به‌روز) ·
