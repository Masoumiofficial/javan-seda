## سنجه‌های تازهٔ این نسخه (۲۳ مورد)

**صف و دکمهٔ کارت**
- `data-tara-queue` روی ظرف فهرست ساخته می‌شود و JSON آن قابل‌خواندن است
- شناسهٔ نوشته در صف حفظ می‌شود (`id`)
- فهرست خالی ⇒ صفر خروجی
- `tara_card_play()` برای آهنگِ بدون فایل، دکمه نمی‌سازد
- `tara_track_list()` سه ردیف می‌دهد ولی فقط دو دکمهٔ پخش (ردیف بی‌فایل هم دیده می‌شود)

**پلیر و پاپ‌آپ**
- `ty-player__playlist` (لیستِ داخل کارت) دیگر وجود ندارد
- دکمهٔ `data-tara-list` با `aria-controls="tara-playlist-modal"` هست
- فقط یک `#tara-playlist-modal` در صفحه
- پیام خطای صوتی (`data-tara-error`) با `hidden` رندر می‌شود
- dock فقط یک‌بار در کل صفحه، حتی با دو `tara_player()`

**شناسنامه و سئو**
- چیپ‌های ترانه‌سرا/آهنگساز/تنظیم از سربرگ نوشته حذف شده‌اند
- `tara_credits_fields()` دست‌نخورده است (شناسنامه همان منبع حقیقت)
- `tara_person_roles()` نقش‌های هم‌نام را در تاکسونومی‌های دیگر پیدا می‌کند
- کارت شخص: `rel="me"` به نقش دیگر + `Person` + `sameAs`
- یک نقش تنها ⇒ کارت شخص ساخته نمی‌شود (بدون باکسِ خالی)

**ویدیو**
- `single.php` از `tara_video()` استفاده می‌کند
- بلوک `<video width="640">` قدیمی نمانده

## چه چیزی آزموده **نشد**

- رندر واقعی مرورگر و پخش صدا (در این محیط مرورگر نیست)
- MySQL واقعی و رفتار کش افزونه‌ها
- تست لمسی/موبایل روی دستگاه واقعی

پیش از انتشار روی سایت اصلی، این سه مورد را دستی ببینید:

1. صفحهٔ اصلی: دکمهٔ پخش کارت → صدا پخش شود، dock ظاهر شود، عنوان dock همان آهنگ باشد.
2. دکمهٔ «فهرست پخش» → پاپ‌آپ باز شود، جست‌وجو فیلتر کند، `Esc` ببندد.
3. صفحهٔ هنرمند: `?sort_audio=title` فقط بخش آهنگ‌ها را عوض کند، آلبوم‌ها دست‌نخورده بمانند.
