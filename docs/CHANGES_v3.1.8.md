## ۱) وضعیت واقعی هاست (از روی مخزن خوانده شد)

شما به نسخۀ **دست‌نخوردهٔ قالب** برگشته‌اید: در `origin/main` هم `javanseda/style.css` و هم `drop-in/style.css` روی
`Version: 3.0.1` هستند و در `javanseda/inc/` **هیچ** فایل `ab-*.php` نیست؛ `myfunctions.php` هم هیچ `require` لایه‌ای ندارد.
یعنی: نه شمارشگر بازدید، نه لایۀ سایدبار، نه پچ‌های 404/صفحه‌بندی/سئو — هیچ‌کدام. (اشکالی ندارد؛ همه تک‌فایلی‌اند و هر وقت خواستید جدا جدا نصب می‌شوند.)

## ۲) چرا «ابزارکِ چارت/محبوبیت» نیست — سه علت، هر کدام یک دقیقه تست

ابزارک «(اختصاصی) موسیقی محبوب (بازدید)» در `inc/widgets.php` این‌کوئری را می‌زند:

```php
'meta_key' => 'views', 'orderby' => 'meta_value_num', 'order' => 'DESC',
'date_query' => array( array( 'column' => 'post_date_gmt', 'after' => '11 month ago' ) )
```

و بلوک «پربازدیدترین آثار ماه» در `inc/mostviews_posts.php` همان `views` را با پنجرۀ «۱ ماه اخیر» می‌خواند.

| تست | اگر … | درمان |
|---|---|---|
| **الف) جای ابزارک** — پیشخوان → نمایش → ابزارک‌ها | ابزارک در ستون «ابزارک‌های در دسترس» افتاده | با ماوس بکشیدش توی «سایدبار» و ذخیره کنید. (جایگذاری ابزارک‌ها در وردپرس به همان نسخۀ قالب چسبیده است؛ وقتی کل پوشۀ قالب را عوض می‌کنید، ابزارک‌ها سرِ جای قبلی‌شان پیدا نمی‌شوند.) |
| **ب) خاموش بودن بلوک خانه** — تنظیمات قالب | گزینهٔ «نمایش پربازدیدترین‌ها» (`index_pv`) **پیش‌فرضش `off` است** | روشنش کنید؛ `تعداد` (`index_nm`) هم خالی نباشد (پیش‌فرض ۸). اگر `index_nm` خالی شود، `posts_per_page = 0` و باکس هیچ پستی نمی‌دهد. |
| **ج) نبودِ داده** — مهم‌ترین علت | کلید `views` در دیتابیس **صفر** سطر دارد | قالب هیچ‌جا `views` را نمی‌نویسد (این همان چیزی بود که دور ۱۲ برایش ساخته شد). ⇒ قدم ۳ |

## ۳) قدم ۳ — یک فایل، بدون هیچ تغییر در قالب

فایل را در این مسیر بگذارید (اگر پوشه نیست، بسازید):

```
wp-content/mu-plugins/ahangban-popular.php
```

```
https://github.com/Masoumiofficial/javan-seda/raw/refs/tags/v3.1.8/mu-plugins/ahangban-popular.php
```

مخزن‌ها (`mu-plugins`) قبل از قالب و افزونه‌ها اجرا می‌شوند؛ پس:

- **هیچ فایل قالب دست‌نخورده نمی‌ماند؟** هیچ فایل قالب عوض نمی‌شود — برای برگرداندن فقط همین یک فایل را پاک کنید.
- چه کار می‌کند؟ ۱) با یک beacon کوچک در `wp_footer` بازدیدِ واقعی را در همان `views` می‌نویسد (سازگار با کش صفحه‌ساز). ۲) **یک‌بار seed**: به نوشته‌هایی که اصلاً `views` ندارند مقدار اولیه می‌دهد تا ابزارک و بلوک خانه **از همین الان** خالی نباشند (بعد از چند روز، ترتیب را بازدیدهای واقعی تعیین می‌کنند). ۳) ضدتقلب: nonce، پنجرۀ ۶ ساعته به‌ازای هر IP+نوشته، ردّ ربات‌ها، بی‌شمردن کاربر لاگین‌شده.
- امن/تمیز: فقط `text`/JSON برمی‌گرداند، IP خام ذخیره نمی‌کند (hash)، در `POST` هم `admin-ajax` است، بدون فیلتر روی `the_content`/`template_include`، بدون ساختار PHP 7.4+ (با `tools/compat-check.py` سنجیده شد: **۰ مورد**)، پارس `OK`.

### تنظیم‌ها (اختیاری — به `wp-config.php` اضافه کنید)

```php
define( 'AHANGBAN_POPULAR', false );            // خاموش‌کردن کامل
define( 'AHANGBAN_POPULAR_SEED', false );       // seed اولیه را انجام نده
define( 'AHANGBAN_POPULAR_SEED_MIN', 1 );       // مقدار اولیهٔ views
define( 'AHANGBAN_POPULAR_DEDUPE_HOURS', 6 );   // پنجرۀ تکرار
define( 'AHANGBAN_POPULAR_SKIP_LOGGED', false );// بازدیدِ خودتان هم شمرده شود
```

## ۴) تست دو دقیقه‌ای

1. فایل را بگذارید → یک بار سایت را باز کنید (seed در دو-سه درخواست اول اجرا می‌شود).
2. با ادمین وارد شوید و بزنید: `https://ahangban.ir/?ahbp=1` → JSON وضعیت: `rows_views` باید ≈ تعداد نوشته‌ها باشد (۴۸ آهنگ)، `seed` = `done`.
3. یک صفحۀ آهنگ باز کنید، ۵ ثانیه صبر کنید، `Ctrl+F5` → در DevTools/Network باید یک `admin-ajax.php` با `action=ahangban_view` (۲۰۴) باشد.
4. پیشخوان → نمایش → ابزارک‌ها: ابزارک «موسیقی محبوب (بازدید)» را در سایدبار بگذارید ⇒ حالا لیست پر است.
5. تنظیمات قالب ⇒ «نمایش پربازدیدترین‌ها» = روشن ⇒ بلوک «پربازدیدترین آثار ماه» در صفحۀ اول پر می‌شود.

اگر عدد بازدید در صفحه دیده نمی‌شود طبیعی است: شمارش در دیتابیس انجام می‌شود و HTML کش‌شده یک بازدید عقب است — بعد از Purge یا تمام‌شدن عمرِ کش درست می‌شود.

## ۵) اگر خواستید همان دور ۱۲ را کامل داشته باشید
