# تغییرات نسخۀ 3.4.2 — رفع دو رگرسیون 3.4.1

دو مشکل که در 3.4.1 وارد شد و اینجا رفع شده:

## ۱) متن `/* v3.4.1 — تنظیمات قالب: لینک «پرش» … */` بالای صفحه

علت: در `header.php` کامنتِ توضیح **بعد از** `?>` نوشته شده بود ⇒ بیرون از بلوک PHP ⇒
به‌عنوان متنِ HTML چاپ می‌شد و چون بلافاصله بعد از `<body>` بود، «افتاده بالای صفحه».
(قاعدۀ همیشگی این پروژه همین بود: هیچ متنی بیرون از `<?php … ?>` / بلوک کامنت CSS چاپ نشود —
این‌جا من نقضش کردم.)

رفع: کامنت به داخل `<?php /* … */ ?>` منتقل شد. خروجیِ صفحه حالا دقیقاً مثل قبل است:
`<body>` ← هوک `wp_body_open()` ← لینک «پرش به محتوای اصلی» (که با گزینهٔ
«لینک پرش به محتوا» یا `define( 'JAVANSEDA_SKIP_LINK', false )` خاموش می‌شود).

## ۲) «پلیر ریخته به هم و از کادر زده بیرون»

علت: برای رفع بریدگیِ ردیف آخر، `overflow:hidden` از کارت برداشته شد (3.4.1) — کارِ لازم،
ولی کارت را بی‌حصار گذاشت. قالب مادر روی فرزندهای پلیر همچنان `float` و
`position:absolute` می‌گذارد:

| خط | قاعدۀ مادر | چه می‌کرد |
|---|---|---|
| 953 / 977 | `.info-box{float:right;width:83%}` · `.progress-box{float:left;min-width:75%}` | اگر flexِ بلوک ۳۰ به هر دلیلی نرسد، ردیف می‌شکند |
| 1040 | `.play-list{position:absolute;top:75px;width:300px;z-index:888}` | لیست عمداً بیرون کارت نقاشی می‌شد |
| 1642 | در موبایل `.track-info-box{position:absolute;top:-40px}` | تیتر به بالای کارت پرت می‌شد |

قبلاً `overflow:hidden` این‌ها را می‌بُرد؛ با رفتنش، هر قاعدۀ جامانده (یا `!important`
لایه‌های دیگر) مستقیم بیرون‌زدگی تولید می‌کرد.

رفع — **بلوک ۳۵** در انتهای `style.css` (خودبسنده):

* `.music_box_player{ display:flow-root; overflow:hidden; min-height:0 }`
  ⇒ جریان مستقل: ارتفاع کارت همیشه جمعِ فرزندهاست و هیچ float بیرون نمی‌زند؛ گوشۀ گرد
  فرزندها را می‌بُرد **بدون بریدگیِ محتوا**، چون لیست از 3.4.1 *داخل* padding کارت است.
* کل چیدمان ردیف (`player` / `player_controls` / `info-box` / `track-info-box` /
  `progress-box` / `progress-cell`) دوباره و کامل نوشته شد تا با کم‌شدن بلوک ۳۰ یا ۳۳ هم
  پلیر سرِ جایش بماند؛ `min-width:0` روی همهٔ فرزندها ⇒ تیتر بلند نوار را هل نمی‌دهد.
* `float:none` روی هر چهار دکمه.
* سقف ارتفاع لیست آلبوم در **همهٔ صفحه‌ها**: `max-height:min(296px,45vh);overflow:auto`
  ⇒ در صفحۀ نوشته هم کارت با آلبومِ ۴۰ ترکي کشیده نمی‌شود.
* موبایل (≤600px) همان سه سطرِ همیشگی: `flex-wrap:wrap-reverse` + دکمه‌ها وسط‌چین.

فاصلۀ پایین پلیر و ۱۹ کنترلر 3.4.1 دست‌نخورده‌اند: `--ab-player-gap` (پیش‌فرض 30px)،
«شکل پلیر»، «فهرست آلبوم»، «دکمۀ صدا»، ستون‌ها/لینک‌های فوتر. اگر خواستید کلاً از کارت
برگردید: «تنظیمات قالب ← کنترل رابط ← شکل پلیر = ساده (قالب مادر)».
