# ترانه یار ۳.۸.۴ — لوگوی شب دیگر زیرِ لوگوی روز نمی‌افتد · کارت لوگو در «تنظیمات قالب»

تاریخ: ۲۰۲۶-۱۰-۲۹ · نسخهٔ قبلی: ۳.۸.۳

## ۱) باگِ لوگوی روز/شب — ریشه پیدا و بسته شد

**علامت:** وقتی «لوگوی شب» تنظیم می‌شد، در حالت روشن هم دیده می‌شد و **زیرِ**
لوگوی روز می‌افتاد.

**ریشه:** در `style.css` این قاعده از قدیم هست:

```css
#header .logo_top img { display: block !important; }
```

این قاعده یک **شناسه + کلاس + عنصر** دارد و `!important` هم دارد. قاعدهٔ
۳.۸.۳ فقط یک کلاس بود:

```css
.ab-logo__img--night { display: none; }   /* بازنده */
```

پس مرورگر لوگوی شب را `block` می‌کرد و چون `figure` ارتفاعِ ثابت ۴۰px دارد،
تصویر دوم **زیر** تصویر اول چاپ می‌شد. (در کشوی گوشی هم همین ریسک بود.)

**اصلاح:** قاعده حالا با شناسه و `!important` نوشته شده و از قاعدهٔ قالب
قوی‌تر است:

```css
#header .logo_top img.ab-logo__img--night,
#mobiles_header .logo_mobiles img.ab-logo__img--night { display: none !important; }

body.night #header .logo_top img.ab-logo__img--day,
html[data-tara-night="1"] #header .logo_top img.ab-logo__img--day { display: none !important; }

body.night #header .logo_top img.ab-logo__img--night,
html[data-tara-night="1"] #header .logo_top img.ab-logo__img--night { display: block !important; }
```

- در **هر دو** فایل `css/tara-ui.css` و `style.css` (چون اگر یکی لود نشود،
  دیگری باید همان رفتار را بدهد).
- تصویر شب دیگر `loading="lazy"` نیست: تصویرِ **پنهانِ** lazy تا لحظهٔ نمایش
  دانلود نمی‌شود و لحظهٔ روشن‌کردنِ حالت شب جای خالی می‌داد. لوگو چند
  کیلوبایت است، پس eager درست‌تر است.
- اگر لوگوی شب تنظیم نشده باشد، اصلاً `<img>` دوم چاپ نمی‌شود (قبلاً هم همین
  بود) ⇒ هیچ‌چیز برای «افتادن زیر هم» وجود ندارد.

## ۲) کارت لوگو در «تنظیمات قالب»

کارتِ «لوگوی سایت — روز و شب» دیگر فقط در پیشخوان پنل نیست:

- **ترانه یار ← تنظیمات قالب** ← بالای فرم، یک کارتِ مستقل با عنوان
  «لوگوی سایت — روز و شب» و توضیح اینکه مقدارها همان گزینه‌های
  «لوگو (حالت روز)» و «لوگو (حالت شب)» در بخش «همگانی» هستند.
- از `admin_notices` استفاده می‌شود: به هیچ قلاب داخلیِ OptionTree وابسته
  نیست و با فرمِ خودِ OptionTree تداخل ندارد (فرمِ کارت مستقل است و به
  `admin-post.php` می‌رود).
- **بازگشت به همان صفحه:** بعد از ذخیره/بازگردانی، به
  `admin.php?page=ot-theme-options` برمی‌گردد و پیام «ذخیره شد» را همان‌جا
  می‌بینید (فیلد پنهان `tara_logo_from=settings`).
- در پیشخوان پنل هم مانده است (جابه‌جا نشد، اضافه شد) و حالا لینکی به
  «تنظیمات قالب» دارد.

## ۳) واکنش‌گرایی و اندازهٔ کادر

استایلِ کارت به فایل مستقل **`css/ab-logo-card.css`** منتقل شد، چون صفحهٔ
تنظیمات CSS پنل را لود نمی‌کند و کارت باید در هر دو جا یک‌شکل باشد.

| مورد | مقدار |
|---|---|
| ارتفاع کادر پیش‌نمایش | **۷۶px** (در ≤۶۰۰px: **۶۴px**) |
| تصویر داخل کادر | `max-height:100%; object-fit:contain` (بدون کشیدگی/بیرون‌زدگی) |
| ستون‌ها | `repeat(auto-fit, minmax(272px, 1fr))` |
| شکست‌ها | ≤۹۶۰px یک‌ستونه · ≤۶۰۰px فشرده‌تر و دکمه‌های تمام‌عرض |
| در صفحهٔ تنظیمات | `max-width:100%` + کادرِ سفید و شعاع ۱۲px، هم‌تراز با فرمِ OptionTree |
| رنگ‌ها | متغیرهای محلی `--logo-*` (بدون اتکا به توکن‌های پنل) |

- استایلِ قدیمیِ کارت از `css/admin-panel.css` **جمع شد** (بدون تکرار).
- CSS فقط در دو صفحه لود می‌شود: `page=taranehyar` و `page=ot-theme-options`.
