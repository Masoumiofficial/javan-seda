## D) یافته‌های حین آزمون (و رفع)

1. **`get_comments( array( 'page' => N ) )` پارامترِ معتبری نیست** (در مسیرِ پشتیبانِ
   `comments.php`). با `number` + `offset` جایگزین شد.
2. **کشِ آمار بر اساس شناسهٔ نوشته** بود؛ اگر تعداد/صفحه در همان درخواست عوض می‌شد، عددِ
   کهنه برمی‌گشت. کلیدِ حافظه شاملِ «کل/در هر صفحه» شد.
3. **کشِ `javan_seda_comments_per_page()`** فیلترهایی را که بعد از اولین فراخوانی ثبت
   می‌شدند نادیده می‌گرفت؛ کش حذف شد (خودِ `ot_get_option` کش است) و فقط گاردِ
   بازگشتِ بی‌پایان ماند.
4. **اعداد ناوبری لاتین بودند** (خروجیِ `paginate_links`). تبدیل به رقمِ فارسی در متنِ
   آیتم‌ها و در `aria-label` اضافه شد؛ هشدار: فقط متنِ بین `>` و `</a|span>` عوض می‌شود،
   نه آدرس‌ها.
