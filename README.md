# ترانه یار — قالبِ موسیقیِ وردپرس

قالبِ اختصاصیِ سایتِ موسیقی: راست‌چین، سبک، بدونِ وابستگی به سرویسِ لایسنس و
بدونِ هیچ ارتباطی با سرورِ بیرونی. رادیو و دی‌جیِ خودکار، پلیرِ چسبان، صفحهٔ
هنرمند، ژانر و حال‌وهوا، مودِ شب، **حسابِ کاربری با ورودِ پیامکی**، **دکمهٔ
«مشاهده در ربات تلگرام» روی هر آهنگ** و پنلِ تنظیماتِ فارسی.
