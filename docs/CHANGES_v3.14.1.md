# ترانه‌یار ۳.۱۴.۱ — تکمیل پاک‌سازی متن پنل

- اعراب غیرضروری (فتحه، ضمه، کسره، تشدید و تنوین) از متن ثابت پنل حساب کاربری، پنل هنرمند و بخش انتشار آثار حذف شد. داده‌های ذخیره‌شده کاربران، نام هنرمندان، متن ترانه‌ها و سفارش‌های قبلی تغییر نکرده‌اند.
- این نسخه ادامهٔ کامل ۳.۱۴.۰ است: زیرمنوهای مستقل «ارسال اثر»، «درخواست‌های پخش آثار»، «آثار من» و «پنل هنرمند»؛ فرم تازه با فایل‌های ۱۲۸/۳۲۰ و کاور؛ درصد پیشرفت مراحل؛ نمایش امن شرایط بدون تگ لفظی؛ پیش‌فاکتور مدیر، پذیرش صریح کاربر، سفارش ووکامرس و لینک پرداخت؛ و پیامک/ایمیل آماده‌شدن پیش‌فاکتور و پرداخت.
- آزمون‌های شبیه‌سازی PHP و DOM، lint همه فایل‌ها و بررسی hash/min اجرا شد. آزمون واقعی وردپرس، ووکامرس، درگاه، WP-Cron، تحویل پیامک، ایمیل، فضای خصوصی و مرورگر/گوشی انجام نشده است.
